Code for Takenoko no Sato は、VRSNS「cluster」にある居住地〈フォレストヒルズ タケノコの里〉を舞台に、そこに住む人、訪れる人と一緒に、課題を見つけ、アイデアを試し、里を育てていくコミュニティです。

現実のまちにシビックテックがあるなら、バーチャルのまちにもあっていい。ワールドの小さな違和感から、誰かの「あったらいいな」まで。コードに限らず、デザイン、企画、対話、そして遊び心を持ち寄ります。
